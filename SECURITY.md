# Reporting sensitive issues

For vulnerabilities or accidental disclosure of private information, contact
**Hao Jiang** at [hao.jiang@dbb.su.se](mailto:hao.jiang@dbb.su.se).
Describe the affected version, behavior, and a minimal synthetic reproduction.
Do not open a public issue containing unpublished data or credentials, and do
not send complete research inputs unless their transfer has been agreed.

This is a development project without a guaranteed response time or a maintained
stable release series. The author will assess reports and coordinate a fix or
correction where possible.

The interface executes locally configured programs and writes calculation files.
Run it with trusted configurations and separate working directories. The release
audit only checks the exported file set and selected patterns; it does not prove
that arbitrary content is safe to publish.
